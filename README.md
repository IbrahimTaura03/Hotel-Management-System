# Hotel Management System

## 📌 Description
A terminal-based hotel management system developed using Python. The application manages room bookings, customer records, and room availability through a command-line interface.

The project focuses on core programming logic, data handling, and simulating real-world hotel operations.

## ⚙️ Technologies Used
- Python

## ✨ Features
- Room booking management
- Customer record storage
- Room availability tracking
- Menu-driven command-line interface

## ▶️ How to Run
1. Clone the repository
2. Navigate to the project directory
3. Run the main Python file using:
   python main.py

- Strengthened Python programming fundamentals
- Practiced logical flow control and data management
- Improved problem-solving and debugging skills
